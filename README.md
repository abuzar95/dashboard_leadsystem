# Prospect Management Dashboard

Dashboard frontend for viewing and managing prospects.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Create `.env.local` file from `.env.local.example`:
```bash
cp .env.local.example .env.local
```

3. Update `.env.local` with your backend API URL (default: http://localhost:3001/api)

4. Run the development server:
```bash
npm run dev
```

The dashboard will run on http://localhost:3000

## Features

- View all prospects in a table
- Filter and search (coming soon)
- User-specific views (coming soon)
